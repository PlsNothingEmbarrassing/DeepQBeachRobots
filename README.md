# DeepQBeachRobots

The training path uses a pure NumPy Gymnasium environment and a masked,
three-step Double DQN implemented with PyTorch and Tianshou. Mesa is not loaded
or installed for training; it remains an optional conventional simulation and
visualisation layer.

## Native Windows setup

Use 64-bit Windows 10/11, Python 3.12, a current NVIDIA driver, and PowerShell.
Run these commands from the directory containing the `DeepQBeachRobots` folder:

~~~powershell
py -3.12 -m venv DeepQBeachRobots\.venv
DeepQBeachRobots\.venv\Scripts\python -m pip install --upgrade pip
~~~

Use the command generated by the official
[PyTorch installer](https://pytorch.org/get-started/locally/) after selecting
Windows, Pip, Python, and the CUDA version supported by the machine. Then install
the pinned project dependencies; the matching installed PyTorch wheel will be
retained:

~~~powershell
DeepQBeachRobots\.venv\Scripts\python -m pip install -r DeepQBeachRobots\requirements.txt
DeepQBeachRobots\.venv\Scripts\python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
~~~

Run the tests and a short smoke curriculum before the full run:

~~~powershell
DeepQBeachRobots\.venv\Scripts\python -m unittest discover -s DeepQBeachRobots\tests
DeepQBeachRobots\.venv\Scripts\python -m DeepQBeachRobots.robots_Q_learning --steps 1000 --output DeepQBeachRobots\training_runs\smoke --require-gpu
DeepQBeachRobots\.venv\Scripts\python -m DeepQBeachRobots.robots_Q_learning --steps 200000 --output DeepQBeachRobots\training_runs\curriculum --require-gpu
~~~

Resume an interrupted run with the same arguments and `--resume`. The CLI is
protected by `if __name__ == "__main__"`, so it is safe with Windows' spawned
process model even though the default trainer does not require subprocesses.

## Optional Mesa simulation

Install Mesa only when the agent-based simulation or visualisation is needed:

~~~powershell
DeepQBeachRobots\.venv\Scripts\python -m pip install -r DeepQBeachRobots\requirements-mesa.txt
~~~

The numerical Gymnasium environment owns the training rules and state. Mesa is
not part of environment collection, evaluation, checkpointing, or inference.

## Throughput benchmark

The benchmark performs legal stage-3 actions directly against the numerical
environment:

~~~powershell
DeepQBeachRobots\.venv\Scripts\python -m DeepQBeachRobots.benchmarks.benchmark_environment
DeepQBeachRobots\.venv\Scripts\python -m DeepQBeachRobots.benchmarks.benchmark_environment --baseline-steps-per-second BASELINE
~~~

The second command exits unsuccessfully if performance is below twice the
recorded commit `85a31ef` median on the same machine.
